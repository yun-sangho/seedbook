## ✨ 새로운 기능

### UI/UX 개선

1. **탭 기반 인터페이스**: 대출 관리와 통계를 분리
2. **빈 상태 처리**: 대출이 없을 때 친절한 안내 메시지
3. **모달 기반 추가**: 더 나은 사용자 경험
4. **드래그 앤 드롭**: 대출 순서 변경 가능
5. **접기/펼치기**: 상세 정보 토글

### 대출 특화 기능

1. **월 이자 자동 계산**: (대출금액 × 이자율) ÷ 12
2. **만기까지 남은 기간**: 자동 계산 및 표시
3. **이자율 입력**: % 단위 표시
4. **대출기관 관리**: 대출기관별 집계

### 데이터 시각화

1. **전체 요약**: 총 대출 금액, 월 상환금, 월 이자, 평균 이자율
2. **대출 유형별 집계**: 유형별 금액, 월 상환금, 월 이자
3. **차주별 집계**: 차주별 금액, 월 상환금, 월 이자
4. **대출기관별 집계**: 기관별 금액, 월 상환금

### 컴포넌트 재사용

- `AssetNameInput`: 대출명 입력
- `AssetValueInput`: 금액 입력 (만원 단위, 한글 변환)
- `SortableList/SortableItem`: 드래그 앤 드롭
- `Card/Badge/Button` 등: 일관된 디자인

## 📝 사용 방법

1. **대출 추가**: 우측 상단 "대출 추가" 버튼 클릭
2. **대출 관리**: "대출 관리" 탭에서 세부 정보 입력/수정
3. **통계 확인**: "통계" 탭에서 요약 정보 확인
   - 전체 요약 (총액, 월 상환금, 월 이자, 평균 이자율)
   - 대출 유형별/차주별/대출기관별 상세 통계
4. **순서 변경**: 드래그 앤 드롭으로 대출 순서 조정
5. **대출 삭제**: 상세 보기에서 삭제 버튼 클릭

## 💡 대출 관리 팁

### 월 이자 계산

- 자동 계산되어 표시됩니다
- 공식: (대출금액 × 이자율) ÷ 100 ÷ 12

### 만기 관리

- 만기일 입력 시 남은 기간이 자동으로 표시됩니다
- 만기가 가까운 대출을 쉽게 파악할 수 있습니다

### 통계 활용

- **유형별 통계**: 어떤 종류의 대출이 많은지 확인
- **차주별 통계**: 누구의 대출이 얼마나 있는지 확인
- **기관별 통계**: 어느 금융기관에서 얼마나 빌렸는지 확인
- **평균 이자율**: 전체 대출의 가중 평균 이자율 확인
